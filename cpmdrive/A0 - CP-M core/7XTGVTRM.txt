; 7xtgv application profiles. Loaded once at boot from A/0/7XTGVTRM.INI.
; Bindings: none, history_previous, history_next, send:, or send_cancel:.
; Ctrl+] x = profile exit; Ctrl+] c = profile clear.
; Escapes: \e \r \n \t \\ \xNN
; Comments must start the line with ';' or '#'; inline ';' is value text.
; exit_key/clear_key names are legacy symbolic action selectors.
; Konsole LAlt+Esc/LAlt+Backspace send them; RAlt is not required.
; Ctrl+Shift+Backspace deletes a recalled history item in any bank.
; history_clear and history_retype_delay_ms describe app line transport,
; not global history deletion; only BBC BASIC currently needs them.

; [global] mode=ansi|vt52 is the boot output decoder; console_bits=7|8
; masks only CP/M console output. FAND's compact 0x9B CSI needs 8 bits.
; A bank may set mode=ansi|vt52 (applied on explicit bank selection),
; input=custom|ansi|vt52|wordstar, and zoomN_terminal=COLSxROWS.
; Existing per-key bindings override an input preset; absent bank mode and
; geometry keys inherit the global/display settings. App mode changes are
; transient, so VT52.COM and VT100.COM never edit this file.
; To try a preset in an existing bank, comment its explicit key lines first.

; Shared-card display defaults, selected by the compiled HAL ID.
; ES3_5 3x/4x deliberately fit without horizontal panning.
; Current view_zoom is saved after a settled keyboard or ZOOM.COM change.
