= Features timeline
:source-highlighter: highlight.js
:toc:
:toclevels: 2

This is a compact history of the *implemented* 7xtgv RunCPM terminal through
`++260928++`. Each `++YYMMDD-HH++` is a source commit or dated implementation
checkpoint, not necessarily the minute a feature first worked on hardware.
Later rows can refine earlier behavior. The
link:../FEATURES.adoc[feature ledger] tracks individual feature states and
test limits; the link:reference-guide.adoc[Reference Guide] describes current
commands. Plans, imported CP/M packages, and the future native 7xtgv format
are not presented here as shipped features. This page is curated, not generated
from `++docs/features.tsv++`; update both when an implemented feature is added,
renamed, or changes behavior.

== Command and catalog name lineage

This table is about *our additions and transitions*, not every supplied
program on the card. `++A0++` and `++A6++` denote intended CP/M drive/user
areas in the project mirror; a `++.ASM++` source in the mirror does not by
itself prove its `++.COM++` is installed on the live device.

[cols="2,1,3",options="header"]
|===
|Name now |First checkpoint |Earlier name or change
|`++VTCPU++`, `++VTCPU8X++`, `++VTDRV++`, `++VTDRV8X++`, `++VTTERM++` (A0, selected A6 copies) |`++260910-01++` |Benchmarks replaced `++VTMHZ++` in the project mirror.
|`++REBOOT++` (A0) |`++260911-18++` |Deferred MCU restart, not a CP/M warm boot.
|`++GCLS++`, `++VTSTART++`, `++VTSTOP++`, `++VTPAD++`, `++SYNC++` (A6 helpers) |`++260912-21++` |Added in stages through `++260914-21++`; `++VTIME.DAT++` is the timing data file.
|`++REFLASH++`, `++UNSUB++` (A0 helpers) |`++260914-21++` |Source introduced then; REFLASH requests a guarded host upload, while UNSUB removes a stranded `++$$$.SUB++` queue.
|`++ZOOM++` (A0 helper) |`++260917-10++` |Original guest zoom helper; later `++VTZOOM++` adds query and explicit temporary logical geometry.
|`++VT52++`, `++VT100++` (A0 helpers) |`++260917-18++` |Transient terminal-mode selection; no INI write.
|`++BBCLOWER++` (A1), `++VTESTS.BAS++` and `++VTDEMO*.BAS++` (A7 mirror) |`++260907-21++` / `++260911-17++` |MBASIC tests/demos were reorganized at recovery; the project-built BBC BASIC lowercase variant was added later. A7 tests continued evolving, notably palette and DEC pages.
|`++VTPAL++` (A0 helper), `++VTPAL.BAS++` (A7) |`++260923-16++` |Palette selection and visual comparison; internal ink order differs from ANSI numbering.
|`++VTPUT++`, `++VTGET++` (A0 helpers) |`++260923-20++` |Existing helpers gained mirror-dialog integration/tagged pages; they superseded the failed XMODEM dialog, not standard XMODEM itself.
|`++UNZIP157++` (A0) |`++260923-20++` |Separate modern ZIP/Deflate extractor; it does not replace an old `++UNZIP.COM++` automatically.
|`++VTINFO++`, `++VTZOOM++` (A0 helpers) |`++260926-08++` |Query current target/view; alter zoom and logical size only temporarily.
|`++7XF++`, `++LS++`, `++LL++`, `++CD++` (native CCP) |`++260926-17++` |Early `++CCPP++` became `++7XF++` on `++260926-23++`; these are built-ins, *not* `.COM` files. `++LS -W++` became `++LS -L++`; `++LL++` aliases the long form.
|`++DIR.7XF++` (per area), `++VOL.7XF++` and `++DRV.7XF++` (A0) |`++260926-23++` |Intermediate `++INFO.TXT++`/`++INFOVOL.TXT++` and `++DRIVE.TXT++` names were superseded. These are catalog/state text files, not real subdirectories; `++CD /A/name++` still selects a flat CP/M DU.
|===

For the exact *current* syntax and limitations, use the
link:reference-guide.adoc#7xtgv-cpm-commands-and-user-areas[command reference].
The live SD card and the local `++cpmdrive++` mirror can differ; this timeline
does not certify that every listed binary is currently installed on the card.
