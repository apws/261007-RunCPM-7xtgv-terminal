= 7xtgv RunCPM terminal guides
:source-highlighter: highlight.js

pass:[<a id="7xtgv-runcpm-terminal-manual"></a>]

The current terminal is a RunCPM-based CP/M machine with a local TFT and a
complete PC mirror. It implements a selected ANSI/VT100 and VT52 subset, not
the planned native 7xtgv terminal. The device's live
`++A0:7XTGVTRM.INI++` may differ from the repository copy.

[cols="1,3",options="header"]
|===
|Read |For
|link:user-guide.adoc[User Guide] |Starting the mirror, everyday keys, zoom/pan, file transfer, safe INI changes, recovery.
|link:reference-guide.adoc[Reference Guide] |Exact commands, keys, profiles, escape-sequence behavior and INI settings.
|link:technical-reference.adoc[Technical Reference] |RunCPM/CCP fork, core and HAL ownership, protocols, persistence, build safety and licensing.
|===

The link:../FEATURES.adoc[feature ledger] records implementation and test
status. Dated reports under `docs/` preserve experiments and hardware evidence;
a historical report is not automatically the current device configuration.
For running geometry and firmware identity, use `++VTINFO++`.
