== Scope and checkpoint

The preceding documentation, renamed-repository references and CSS/JS work
was committed and pushed as `7dcdf5a`. This follow-on reviews practical guide
content and implements the user's request for shorter, topic-separated prose.
It does not finish the entire manuals review or hardware acceptance.

== User Guide changes

* Separated mirror, panel viewport, guest DU and host transfer DU in the introduction.
* Split profiles/history into selection, everyday shortcuts, emergency return,
  recall and RAW input. Expanded shortcut pairs to repeat their modifiers.
* Clarified the transient selection label and CCP-only `on_select` command;
  direct number selection exits RAW, while previous/next browsing does not.
* Replaced the geometry paragraph with a command table and application-size checklist.
  Select a profile before setting geometry because it can apply its own override.
* Split palette/emphasis from backlight; noted first adjustment from OFF restores
  the remembered level and SDL brightness is not physical light-output calibration.
* Made the MBASIC recipe use the card's actual MBASIC area and explicit 80x24
  geometry; linked menu choices to attributes, DEC graphics, VT52 and full-row scrolling.
* Explained that the Mandelbrot scripts use fixed pixel positions and may clip
  on smaller panels; EP4_10 desktop is a spacious first demonstration.
* Reworked transfer and INI editing into short steps, examples and safeguards.
  Desktop direct file edits require closing the emulator; device fetch/edit/send
  remains a separate workflow with explicit write approval.

== Reference Guide changes

History persistence, effective CCP bank versus selected profile, RAW input,
INI selection overrides, MBASIC adapters and BBC BASIC retyping now have short
subsections and single-level bullets. Existing parent anchors were preserved.
This is not yet a full Reference Guide default/command/escape-sequence audit.
