= Explicit Windows row configuration handoff
:source-highlighter: highlight.js

== Evidence and cause

Follow-up to
link:261011-2148%20DONE%20Windows%20row%20conversion%20native%20diagnostic.adoc[the native diagnostic].
ES3_35 report `desktop-win/msys2-ucrt64/jc8048w535/key-row-2076.log` contains:

----
Layout=0000000004050409 native-config-length=0 match=0
Configured: 0000 0000 0000 0000 0000 0000 0000 0000 0000 0000
Detected: 002B 011B 0161 010D 0159 017E 00FD 00E1 00ED 00E9
First row: scan=02 vk=31 mods=0 extended=0 composing=0 altgr=0 win=0 match=0 fallback-bytes=0 packet-bytes=0
----

The detected layout exactly matches the configured Czech row. Python's session
log has the correct setting, but GetEnvironmentVariableW inside Mintty returns
no value. This establishes a configuration handoff failure at the MSYS/native
process boundary, not a mismatch in the measured row. The HKL also explains why
the original low-word Czech-language test was insufficient.

== Correction

Python now encodes the validated ten BMP characters as a forty-character ASCII
hex command argument; a dash explicitly disables conversion. The native owner
validates the argument and sets ten immutable, namespaced properties on the
already selected Mintty window before installing its thread hook. The DLL reads
that window configuration directly. Normal shutdown and installation failures
remove the properties; window destruction also ends their lifetime.

The DLL no longer obtains this setting from its native environment. Launcher
configuration remains `XTGV_HACK_TOPROW` in `tools/terminal.conf`, with inherited
Python environment precedence and empty disabling. Existing brightness, decimal,
AltGr, punctuation and firmware INI behavior remain as before.
The bounded diagnostic now labels the source `config=window-properties` and
reports enabled/match status. No typed text is recorded.

== Validation and next check

Portable C++ tests cover exact Unicode-to-hex decoding, disabled input, invalid
length/hex/control/surrogate rejection and existing key mappings. Python tests
verify explicit native command arguments for configured and disabled rows.
All 32 Windows tooling tests pass. Both native helper targets cross-build with
CMake and independently with warnings treated as errors.
