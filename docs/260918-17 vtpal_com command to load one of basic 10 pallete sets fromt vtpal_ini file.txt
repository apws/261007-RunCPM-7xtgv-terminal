 VT100/ANSI - alternativni pojeti ANSI atributu !!!!
            - mame tam ted HIGHLIGHT, UNDERLINE, INVERSE, BLINK
               - (ale UNDERLINE, INVERS a BLINK nepodporuje nativni 7xtgv !!!)
               - tedy, mame POUZE 4 background/paper barvy v TEXT modu => musime to nejak namapovat !!!!
            - tzv. muzeme modifikovat UNDERLINE, INVERSE a BLINK na alternativni pozadi z background/paper palety "pale RGB""
              - INVERSE as "pale blue" (default)     - pro DARK/CRT mode: DARKER BLUE a default (WHITE ink, so in fact "inversion")
                BLINK as "pale red" (default)        - pro DARK/CRT mode: DARKER RED a default (WHITE ink, so in fact "inversion")
                UNDERLINE as "pale green" (default)  - pro DARK/CRT mode: DARKER GREEN a default (WHITE ink, so in fact "inversion")
                (pale green slouzi TAKE jako default "cursor line")
            - "pale" RGB colors mohou byt pro BLACK CRT GREEN/AMBER INK modifikovany na "dawn" RGB (temne, pouze RGB odstiny)
