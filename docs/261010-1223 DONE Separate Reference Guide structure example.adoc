== Proposed grouping

[cols="1,3",options="header"]
|===
|Part |Current material grouped or split
|1. Terminal operation |Mirror/session reference; global terminal controls, chord table and prefix fallbacks.
|2. Applications and input |Profiles and selection; history and active line; application editing adapters; RAW.
|3. CP/M commands and files |7XF and catalogs; DU inventory; shared commands; startup/SUBMIT; transfer and extraction.
|4. Configuration |INI syntax/reload; key names, presets and precedence; global, display, profile and palette settings.
|5. Terminal interfaces |Output modes and sequences; text attributes/color interpretation; a concise interface map; xterm256 plotting behavior.
|Appendix A |Detailed diagnostic procedures, benchmarks, visual tests, palette tests and plotting demos.
|===

The example has five explicit, provisional part numbers and 22 unnumbered
topics. Each topic explains its scope and links to existing source material.
Semantic anchors are separate from the displayed labels; existing live-guide
anchors are untouched.

Configuration versus runtime behavior, palette definitions versus SGR mapping,
and plotting interface versus demos are deliberately separated. The interface
map is a proposed curated index, not a new duplicated protocol specification.
Internal parser/publication, storage and transfer-framing details are proposed
for TRG ownership; no text has actually been moved.

  avoid typographic substitution in the generated link.

* Preview and preservation inventory: `/tmp/xtgv-rg-structure-example/`.
  Styled HTML is under its `docs/` folder; screenshot is `toc-preview.png`.

Only the new example/checkpoint and documentation registry/navigation change.

commit or push action. Review the part names, boundaries and numbering policy
before separately choosing any migration of live-guide content.
