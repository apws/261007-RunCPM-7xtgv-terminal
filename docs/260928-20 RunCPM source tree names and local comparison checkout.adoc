`++src/RunCPM_comparison/++` is ignored by the root `.gitignore`. It is an
independent local clone of this repository, detached at full commit
`++35fb6b13317788bdd1fe9448a94c96f582c888c2++` (`++260906++`,
"Run CP/M with second-core random print"). That commit predates the present
`++src/++` layout; the historical tree is therefore at
`++src/RunCPM_comparison/7xtgv_RunCPM/++`, not under another `++src/++`.
It can be compared in VS Code with
`++src/RunCPM_7xtgv-terminal/++` or `++src/RunCPM_7xtgv/++`.
The checkout is not Mockba's current HEAD, and no upstream code was fetched.

This is intentional: the clone's *HEAD* remains `++35fb6b1++`, but its
working files are not a pristine historical tree. For reproducible old
contents use `++git -C src/RunCPM_comparison show HEAD:7xtgv_RunCPM/ccp.h++`
(and the analogous path for each other file). Do not reset or overwrite
Petr's comparison copies merely to make that checkout clean.
