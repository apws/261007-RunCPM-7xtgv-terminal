= Browser focus and shortcut panel update
:source-highlighter: highlight.js

== Requested behaviour

* Remove the browser Ctrl+] focus-release interception. It now follows normal
  control-key encoding into the guest (0x1d), retaining keyboard capture.
  Clicking/tapping a page control leaves capture; clicking/tapping the display
  resumes it. The separate native mirror prefix is unchanged.
* Guides starts with Alt+Backspace clear screen and Alt+Q exit app, followed by
  backlight Alt+Ctrl+Shift+PgUp/PgDn and profile Alt+Space/PgUp/PgDn controls.
  Existing history, named prompt, browse/change reference and guide links follow.
* Controls no longer repeats clear/exit or profile instructions, including the
  profile line formerly in expanded keyboard help. Glyph-zoom and keyboard
  configuration help remain there.
* The user reports usable Android mobile operation. Device/browser versions
  and a complete touch/keyboard matrix were not supplied; UG records the report
  without claiming complete Android qualification.

Ctrl+] had supplied a keyboard-only route out of capture. Its removal is the
explicitly requested behaviour; no substitute browser escape chord is added.
