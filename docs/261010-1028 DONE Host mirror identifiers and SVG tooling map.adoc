== Implemented rename

* The standard hardware tmux session is now `7xtgv-terminal`. The default in
  `tools/cpm-session.sh` and stop references in `tools/target_reflash.py` and
  `tools/fetch-7xtgvtrm-ini.sh` agree on that name.
* Konsole source files are `tools/7xtgv-terminal.profile` and
  `tools/7xtgv-terminal.keytab`. Their visible labels and keyboard-table
  identifier use `7xtgv-terminal`. `kon.sh` installs/selects these names.
* The key-event generator and existing profile/keymap tests follow the renamed
  files. Current guides, desktop README and repository instructions use the new
  identifiers. The Kitty header identifies the terminal consistently.
* `cpm-session.sh`, `kon.sh`, `kit.sh`, Kitty configuration filenames and
  `7xtgv-desktop-<PID>` remain as before. No key-binding bytes, application
  presets, session lifecycle policy or environment variable names changed.
* Dated records retain their historical names and evidence. The three earlier
  reader-context reformulation questions remain separate and unanswered.

== Adoption and remaining boundaries

New Konsole launches install the renamed files into the user data directory.
Existing windows retain their loaded settings; existing sessions are not
automatically renamed or stopped. Close a pre-update hardware mirror before
launching the replacement so that only one bridge owns its serial endpoint.
Old installed Konsole files are retained; cleanup is not required for adoption.

The shell helper's `XTGV_SESSION` override remains supported, while hardware
reflash/INI-fetch helpers stop the standard session name. Generalizing their
custom-session policy was outside this requested rename.

No firmware/core/HAL edits or builds, guest deployment, INI/history changes,
hardware writes, commit or push. Physical/GUI acceptance of the new names
remains the next normal mirror launch.
