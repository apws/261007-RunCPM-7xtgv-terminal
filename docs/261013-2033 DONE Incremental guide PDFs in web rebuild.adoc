= Incremental guide PDFs in the web rebuild
:source-highlighter: highlight.js
:toc:

== Result

The common `tools-web/desktop-rebuild.sh` now refreshes stale numbered guide
PDFs before compiling and packaging the browser application. Normal launch,
native desktop/MCU builds and direct Pages packaging retain the saved PDFs.
The six PDF files remain intentionally versioned in `guides/pdf/`, together
with `print-manifest.json`; readers need no printing tools.

`print_guides.py` converts embedded AsciiDoc into the Live Preview content
wrapper, applies the shared root CSS/JS, then prints in Chromium via
Playwright. Settings are portrait A4, scale 1, 0.4-inch default-sized margins,
background graphics enabled and browser headers/footers disabled. Liberation
Sans/Mono are required. Images load locally; no remote rendering resources
are fetched. Code uses the shared monospace style without CDN highlighting.
Relative document links point to GitHub; fragment/TOC destinations remain
inside the PDF. No workstation-local file URLs are allowed in saved links.

== Freshness and failure behavior

* Per-guide source hashes and shared CSS, JS, guide-image, printer and Python
  requirement hashes select stale output. Edited/missing PDF files are
  refreshed too. Shared formatting/image changes conservatively reprint all.
* The manifest records settings, input/output hashes, page counts and renderer
  versions. Renderer upgrades alone do not invalidate reviewed snapshots;
  `--force` adopts a new renderer explicitly.
* A no-change rebuild preserves saved PDF bytes and modification times. It
  does not launch Chromium or require the print-only system tools.
* All pending prints are staged and checked for loaded images, A4 dimensions,
  readable text and absence of local file links before any replacement.
  Render/validation failure preserves the saved PDFs and manifest.
* Concurrent input/output edits abort printing. Destination-local staging
  permits preview folders on another filesystem; individual PDF replacement
  is atomic, and the manifest is replaced last.
* `--output-dir` provides isolated previews; `--check` writes nothing and
  returns 1 for stale output. Web shortcut details go to its adjacent log.
* Explicit setup installs the Playwright browser, with documented external
  Asciidoctor/Poppler/font prerequisites. The manual Pages workflow supplies
  these before rebuilding. No workflow was dispatched for this change.

  build. Packaged PDFs match saved files exactly. Freshness check, frontend

  also passed.
