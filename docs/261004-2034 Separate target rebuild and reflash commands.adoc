= Separate target rebuild and reflash commands
:source-highlighter: rouge

== Layout and behavior

All six modules use `tools/targets/TARGET = DISPLAY_ID/` folders, following
Petr's EC6_147 example. Target JSON metadata stays in `tools/targets/`.

* `rebuild.sh`: compile and stage a fresh candidate; no device or mirror access.
* `reflash.sh`: upload staged `new`, otherwise `current`; no compilation.
* Separate adjacent `rebuild.log` and `reflash.log` retain detailed commands,
  image paths and section delimiters. Existing reflash logs were preserved.
* Conditional connection prompts, target checks and mirror restoration remain
  unchanged. No automatic promotion or recovery bypass.

[source,sh]
----
cd "src/RunCPM_7xtgv-terminal/tools/targets/esp32c6-lcd-1-47 = EC6_147"
./rebuild.sh
./reflash.sh
----
