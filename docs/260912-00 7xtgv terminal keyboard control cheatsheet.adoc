Historical keyboard-control note. The mappings and future-extension notes below are preserved from the source; consult the current terminal manual for current behavior.

== Profile range

[source,text]
----
future extension: 16 instead of 10 profiles (hex)
(allowed for ALL user areas of current drive)
profiles 0-15 0123456789ABCDEF = A user areas
----

== Modifier abbreviations

[source,text]
----
ALT = LALT
CT  = Ctrl
SH  = Shift
----

== Terminal control

[source,text]
----
q - ALT+CT+ESC  = TERM QUIT [[ / RESTART ]]
r - ALT+CT+SP   = TERM refresh TFT and PC mirror
----

== Application control

[source,text]
----
c - ALT+BS      = CLS
x - ALT+ESC     = QUIT (app) [[ REBOOT (ccp) ]]
----

== Profile selection

[source,text]
----
# - ALT+#       = profile toggle ## RAW
[ - ALT+PgUp    = profile prev #0
] - ALT+PgDn    = profile next #n
----

== Viewport edges

[source,text]
----
a - ALT+HOME    = viewport left       (ALT+SH+Q)
e - ALT+END     = viewport right      (ALT+SH+W)
# Partial panning is retired.  Only the two global edge jumps above remain.
----

== Backlight

[source,text]
----
b - CT+] b 0..32 = direct backlight off / 32 levels (CT+SH or ALT+SH + 0..9
    selects off / coarse 20..100%; CT+SH or ALT+SH + PgUp/PgDn moves 1 step)
    First PgUp/PgDn from off restores the saved level. The last non-off level
    is safely persisted as [global] backlight_level in 7XTGVTRM.INI.
    CT+SH or ALT+SH + Home/End = viewport left/right edge
----

== Zoom

[source,text]
----
+ - LALT+CT+SH+PgUp = glyph zoom in             (CSI >66v)
- - LALT+CT+SH+PgDn = glyph zoom out            (CSI >67v)
----

== History

[source,text]
----
p - up          = history line prev  (ALT+up)
n - down        = history line next  (ALT+down)
    Type a prefix and leave cursor at its end: Up/Down browse only lines
    beginning with that exact prefix. Empty or mid-line input browses all.
    Down past the newest match restores the typed prefix.
    CT+SH+Backspace deletes the recalled line; next Up continues older.
----
