:leveloffset: +2

Status: completed ESP32-S3 work, 13 September 2026.

== Terminal configuration

The terminal now accepts a global cursor blink setting in `+7XTGVTRM.INI+`:

[source,ini]
----
[global]
cursor_blink_ms=250
----

The former built-in interval was 500 ms. The value is parsed as milliseconds and accepted from 1 through 5000. The ESP32-S3 firmware was rebuilt and flashed, and the 250 ms blink was confirmed on the TFT after reboot.

== CP/M source and TE compatibility

The installed TE v1.11 editor rejects source lines longer than 80 columns. All authored `+.ASM+` and `+.SUB+` files in `+cpmdrive/+` were scanned; the only real overlong lines were comments in `+A6/brot-ps.asm+`, which were shortened. Ctrl-Z record padding was excluded from the scan.

Text uploaded with `+tools/cpm-transfer/transfer.py --cpm-text+` is converted to CP/M CR/LF records and receives a trailing Ctrl-Z. The host mirror remains ordinary Git text. All 36 ASM/SUB files were reuploaded to their matching CP/M user areas (A4, A5, A6, A9, and AC).

TE profile selection normally sends `+A0:+`. To edit a file stored on A6, first select A6 or open it with a drive-qualified name when TE accepts it:

[source,text]
----
A6:
TE BROT-PS.SUB
----

== SUBMIT arguments and benchmark helpers

RunCPM `+SUBMIT.COM+` expands positional parameters in the script. For example, `+VTPARG.SUB+` contains:

[source,text]
----
VTPAD $1
----

and `+SUBMIT VTPARG 3+` was verified to execute `+VTPAD 3+` and emit three blank lines. The benchmark scripts currently use `+VTPAD 15+`; changing that record to `+VTPAD $1+` will allow commands such as `+SUBMIT BROT-PS 15+` to select the padding count.

`+VTPAD.ASM+` is a small CP/M utility that emits a requested number of CR/LF pairs, defaulting to its built-in count when no argument is supplied. The VTSTART/VTSTOP sources and BROT scripts are kept in the A6 source mirror.
