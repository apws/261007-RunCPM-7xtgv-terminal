== Next-session agenda

  implemented; this is a review/test task, not an assumption that it is missing
  or broken. Start with VTESTS's DEC graphics page and the existing notes.
  Check glyph appearance, joined line drawing, font/zoom behavior and charset
  reset behavior on the current display.
. *Consider a CRT scanline experiment.* Optional visual treatment for the dark
  themes, independent of terminal attributes. Agree on the appearance first;
  preserve legibility and existing palette behavior. No scanline implementation
  is approved or performed by this note.
. *Investigate the boot/reboot brightness flash.* Petr sees the TFT "shining"
  at apparently full backlight for roughly half a second during startup in dark
  modes. Treat duration/full brightness as an observation, not a measurement.
  Trace backlight pin/PWM initialization, initial framebuffer clearing, palette
  loading and saved-level restoration. Distinguish a bright initial screen
  from an actual full-duty backlight pulse before choosing a fix. No cause is
  established yet. Preserve level 1's usable floor and level 32's full-on state.
