= Browser VTINFO and VTZOOM reply timing
:source-highlighter: highlight.js

== Problem and cause

VTINFO printed NOT SUPPORTED (timeout), then the DCS identity response appeared
as text at the CCP prompt. VTZOOM could apply its requested geometry and still
print the same timeout because its subsequent query used the same reply path.
The terminal supported both commands; the failure was scheduling.

The guest helpers poll BDOS input at most 65535 times per byte. The fast Wasm
worker could exhaust that loop before the UI owner's next animation frame
parsed the queued output. Replies generated during that pass were also left
in a staging queue until a later terminal pass. Removing only the latter delay
passed a host regression but still reproduced the browser failure.

== Change and ownership

* Browser-only virtualAvailable yields for 1 ms when input is empty and guest
  output is waiting for the UI owner. Available input and polling with no
  pending output retain their immediate path. CPU-only execution is untouched.
* The terminal delivers replies generated while consuming output in the same
  pass, before rendering/mirroring, with the existing free-space and forced-
  return checks. Deferred replies remain bounded; output still drains when
  guest input is full.
* Desktop work-pending detection includes deliverable replies, even without a
  connected mirror. The UI owner remains the sole terminal/parser producer.
* No RunCPM core, BDOS/BIOS, guest helper source/binary or card settings changed.
  The existing VTINFO.COM and VTZOOM.COM work with the corrected runtime.

== Artifacts and boundaries

Standalone and Pages packages are refreshed. Existing local launcher sessions
serve immutable older copies: export wanted card changes, relaunch the local
web launcher and open its new page to use the fixed build. No need to replace
guest COM files. No publication, commit, physical-board rebuild or flash was
performed. MCU and native-desktop acceptance remain separate from this browser
proof; background-tab throttling is not qualified.
