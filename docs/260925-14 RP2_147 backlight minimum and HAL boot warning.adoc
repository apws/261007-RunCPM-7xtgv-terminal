:leveloffset: +2

== Decision

Following `260925-12 RP2_147 visual checks and delayed save stalls.adoc`,
Petr explicitly chose to retain full maximum PWM. The requested minimum is
the former logical level9, which means electrical duty17/255. Indicator
offset10px was already prepared following acceptance of the30px placement.

Only the RP2_147 backlight table is changed. Level0 remains OFF; levels1-31
use gamma2.2 across17..255 with a rising floor to keep every level distinct:

----
max(17 + level - 1, 17 + round(238 * ((level - 1) / 30)^2.2))
0,17,18,19,20,21,22,24,27,30,34,38,43,49,55,62,
69,77,85,94,104,115,126,137,150,163,176,191,206,221,238,255
----

This changes the electrical meaning of existing saved logical levels; no INI
value is rewritten or transferred. The current running firmware remains
260925-1314 until a separately requested rebuild and flash.

== Generic module warning

`DisplayHalDefaults::bootWarning` is optional plain text for every HAL.
Existing W550, W535 and RP2_2 defaults are null. RP2_147 supplies:

----
WARNING: avoid prolonged max backlight.
----

This is a requested precaution, not a claim that the C6 vendor thermal warning
establishes a tested maximum for this RP2350 board. The actual C6 warning and
its source are recorded in the preceding note. Full PWM remains selectable.

The sketch emits the notice once after the initial CCP version header and
before the first prompt; warm boots and VER do not repeat it. ANSI mode uses
implicit ink on red paper, clears the remainder of that line in red, then
resets attributes before CR/LF. VT52 mode emits plain text. Headless builds
are unchanged. The ordinary output path also carries it to the PC mirror.
At narrow zooms the message may wrap; no geometry or mode switching is added.

== Validation and boundaries

All four HAL backlight tests pass for both polarities (eight runs), covering
endpoint duties, strict monotonicity, gamma formula, startup hold, timed ramp
and cancellation. Ten host target tests pass. The boot-warning test uses the
production terminal parser to verify red paper across the line and ordinary
paper on the following prompt; null/empty notices and VT52 fallback pass.

No rebuild, flash, promotion or SD transfer. The autosave stall is not fixed
or instrumented by this change. Next: requested rebuild/reflash, then Petr's
visual checks of the new minimum, step spacing, warning and10px indicator.
