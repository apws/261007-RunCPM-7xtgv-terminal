== Implemented

* Existing real board selector plus `XTGV_DESKTOP=1`: all six headers retain
  identity, geometry, limits, defaults, offsets, drawing policy and backlight
  curve. Only physical implementations are suppressed. No duplicate SDL board.
* Original Arduino sketch, abstraction and 7XF run natively. No CPU, BDOS,
  CCP, disk or console edits. The previously approved sketch reporting seam
  emits a truthful host-storage banner instead of SPI MHz.
* Real Arduino_GFX 1.6.4 Canvas draws RGB565; SDL only presents it. Buffered
  boards publish on `flush()`, copying pixels immediately; direct boards
  publish changed drawing batches. INI `render_flush_hz=10` remains effective.
* Main thread owns terminal/Canvas/SDL; worker owns RunCPM/filesystem.
  `runtime_desktop.h` coordinates; coherent host services remain in `desktop/`.
* Raw Linux PTY carries the existing full mirror protocol, bounded queues and
  partial writes. Explicit `--desktop-pty` skips USB DTR and disables upload.
  Launcher uses a separate desktop Konsole/tmux session; no `terminal.conf`
  edits and no stopping the physical mirror.
* EXIT, window close, Ctrl+C and REBOOT cooperatively stop the guest. The
  existing product-owned abort hook and delay/yield shims check the stop flag.
  The worker unwinds, disables cancellation for persistence, closes tracked
  handles and joins. REBOOT returns 75; the launcher starts a fresh process.
* Host SD/File compatibility uses ordinary binary host files and an explicit
  root. Case follows the host filesystem. Uppercase inventory/apply is separate.
* CARDMARK reports unsupported on desktop. Removed the abandoned W535 SD_MMC
  header, selector, flag and fallback tests; historical documents/git retain it.

== Build and run

See link:../src/RunCPM_7xtgv-terminal/desktop/README.adoc[desktop requirements and commands].
Linux, C++17, CMake 3.19+, Python 3.10+, SDL2 development files and Arduino_GFX
1.6.4 are required. Konsole/tmux provide the mirror. No Arduino MCU core or
SdFat hardware driver is needed by the native build.

From the repository root:

[source,bash]
----
python3 src/RunCPM_7xtgv-terminal/desktop/desktop.py build --target EP4_10
python3 src/RunCPM_7xtgv-terminal/desktop/desktop.py run \
  --target EP4_10 --card-root ./cpmcard
----

WARNING: Normal runs can write guest files and INI/history. Use a copy first.
For the mounted reader, explicitly use `--card-root /run/media/falken/RunCPM`.
Close before unmounting; never run two instances against one tree.

Build refreshes the stamp; run never silently rebuilds. All six display IDs
and their long target IDs are accepted. Artifacts and `build.log` live in
`build/RunCPM_7xtgv-terminal/desktop/<target>/`, separate from MCU candidates.

[source,bash]
----
python3 src/RunCPM_7xtgv-terminal/desktop/desktop.py test --target EP4_10
python3 src/RunCPM_7xtgv-terminal/desktop/desktop.py matrix
python3 src/RunCPM_7xtgv-terminal/desktop/card_names.py ./cpmcard
----

The final command only inventories; `--apply` explicitly renames. Neither
original tree was normalized here. Petr's proposed future move from `cpmdrive`
to `cpmcard` tooling remains separate; no automatic synchronization was added.

== Visual observations and limits

Petr saw the dark SDL display and liked that low-brightness end. Copied INI
`backlight_level=10` maps to P4 PWM duty 21/255; direct texture modulation is
darker than the physical LCD. Keep this approximation for now. Neither INI nor
hardware curve changed. PPM captures the drawing Canvas without brightness or
scaling, not necessarily the last published texture.

Always-on-top/no activation are window-manager requests; click focus is not
guaranteed. SDL ignores keys; input belongs in the mirror. MCU speed, buses,
DMA, panel scanout and electrical reliability are not simulated.
