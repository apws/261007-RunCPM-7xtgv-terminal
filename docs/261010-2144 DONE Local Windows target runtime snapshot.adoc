== Implementation

`tools-win/stage-local.cmd` dispatches `windows_stage.py` through the existing
MSYS2 bootstrap. ES3_5 is the default; `--target` selects another already-built
target and `--destination` changes the parent directory. Each run creates a fresh
dated target directory. No overwrite/refresh of previous local cards or runtimes.

The copy contains `xtgv_desktop.exe` and all DLLs staged beside it, selected-target
metadata and three target launchers, the required Python mirror/owner/keyboard/
transfer helpers, key identifiers and a complete card copy. Existing relative
path discovery is retained through a small repository-shaped subtree. The root
has convenient desktop-local/test/card.cmd wrappers. The copied dispatch supports
launching only. MSYS2 remains an installed prerequisite, discovered normally.

The complete card is copied under the existing coordination lock, excluding only
that transient lock. An active source-card writer causes a refusal without
stopping it. Repository private/archive trees, other targets, compiler caches and
build dependencies are excluded; copied card private data remains part of the
complete card. License/reference notices accompany this personal test snapshot.

The local launcher persists changes within the copied card. The test launcher
makes a fresh session-card copy. Logs also remain local; there is no automatic
synchronization or access to W: during ordinary launch. A manifest records source
paths and copied-file SHA-256 hashes. No production storage/emulator/core changes.
