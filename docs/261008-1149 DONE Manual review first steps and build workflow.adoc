== Scope

== Changes

* link:../guides/01-BG-build-guide.adoc[Build Guide] now starts with clone, explicit
  setup, display-ID-first target folders and desktop rebuild/launch. All six
  shortcuts are together; manual dependency details and optimization come later.
* Cross-checked behavior against `setup.sh`, `setup_serial.py`, `fresh-build.sh`,
  target JSON/profiles, `target_desktop.py`, `target_reflash.py`, `target_mirror.py`,
  `card_paths.py`, desktop launcher/CMake and mirror scripts.
* Described actual path precedence: local launch uses `XTGV_CARD_ROOT` by
  default; mounted launch uses `XTGV_DESKTOP_CARD_ROOT` or an interactive prompt;
  explicit `--card-root` wins. Mounted mode checks for a real mount root.
* Separated rebuild, existing-image upload and running firmware identity.
  Preserved mismatch/BOOTSEL guards, mirror restoration limits, USB access and
  card-provisioning boundaries. `mirror.sh` has neither a dry-run option nor a
  matching adjacent log; the other five wrappers have workflow previews/logs.
* Separated combined setup from native build requirements: setup installs both
  MCU and desktop dependencies; desktop compilation itself needs no MCU core
  or USB uploader. Custom GFX sketchbook location is covered.
* link:../guides/02-UG-user-guide.adoc[User Guide] now opens with per-board desktop
  and hardware launchers. Added desktop card ownership, shutdown/focus and
  INI-edit distinctions; CARDMARK/REFLASH are not presented as desktop features.
* Fixed the User Guide's transfer link: AsciiDoc was turning its double hyphen
  into an em dash. Preserved literal double hyphens in the README/Build Guide
  target-folder tables so copied folder names are usable.
* Aligned the guide index/README and corrected the old manual-folder link in
  `cpmcard/README.adoc`. No guest files were changed.
* Corrected the Reference Guide's two current-support statements about the
  abandoned W535 SD_MMC alternate. Desktop storage has no physical SPI clock
  and no raw-card diagnostic. Historical timeline entries remain unchanged.
* Fixed two pre-existing missing links in the hand-maintained feature-ledger
  notes: private code-monitoring material is no longer linked as public;
  compatibility reading points to retained original/review/checkpoint records.
