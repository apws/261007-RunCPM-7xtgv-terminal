== Working-state preservation and concurrent activity

The pre-test inventory hashed 301 working-card files. After testing, 300 are
unchanged and only `cpm(A0)/7XTGVTRM.BUF` differs; no file was added/deleted.
The INI and its six host snapshots remain unchanged.

The EP4_10 `desktop-local.log` records a separate launch at 18:51 on the actual
working card with build `261009-1850`. The BUF mtime is 18:52:56. This is
consistent with a concurrent ordinary desktop history save; the log alone
does not establish every action taken in that session. Our automated commands
used explicit separate disposable card roots. The current BUF is preserved,
not restored over the concurrent state.

No physical SD synchronization, guest deployment, MCU staging/flash,
commit or push occurred. All other accumulated changes remain in place.
