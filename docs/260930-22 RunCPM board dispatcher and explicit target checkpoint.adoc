== Source placement and target selection

* The root `++RunCPM_7xtgv-terminal.ino++` now includes one
  `++hardware/arduino_7xtgv/board.h++`. That dispatcher selects the existing
  per-module storage header and owns the same `++SD++` instance and `++File++`
  type selection previously written in the sketch. Storage implementation,
  pins, clock, and startup flow remain otherwise unchanged.
* W535 and RP2_2 target JSON profiles now supply explicit board defines,
  matching the already-explicit W550 and RP2_147 profiles. Arduino builds
  with zero or multiple target defines stop at `++runcpm-config.h++` instead
  of silently using the ESP32-S3 or RP2040 architecture fallback. The
  target-free host-test geometry still defaults to RP2_2.
* A direct Arduino build without a named target profile now fails by design;
  use the target-aware builder. No `++XTGV_RUNCPM++`/`++XTGV_TERMINAL++`
  composition flags or standalone UART mode exist yet.
