== Change

The desktop launcher now drains output with a selector while checking its
mirror process. Closing Kitty/Konsole or ending the current-terminal
attachment sends SIGTERM to the desktop child. The existing native signal
handler requests cooperative worker/storage shutdown. The launcher waits
for that shutdown before cleaning up only its own desktop tmux session.
It does not force-kill the emulator during normal close.

Closing SDL or guest EXIT still cleans up the mirror. A terminal process
that remains after tmux cleanup gets a bounded terminate/kill fallback.
Closing the mirror wins over a simultaneous guest REBOOT. The launcher also
keeps the native executable path separate from the mirror executable,
preserving executable lookup across guest reboot.
