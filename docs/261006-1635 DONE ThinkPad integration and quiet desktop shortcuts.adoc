== Simple launchers

All six `tools/targets/DISPLAY_ID -- target/` folders now contain:

[cols="1,2",options="header"]
|===
|Script |Purpose
|`desktop-rebuild.sh` |Fresh native build for that board; no MCU build/flash.
|`desktop-local.sh` |Last native build using repository `cpmcard`.
|`desktop-card.sh` |Last native build using an explicitly selected mounted SD/USB root.
|===

Mounted-card selection: `--card-root PATH`, `XTGV_DESKTOP_CARD_ROOT`, or a prompt.
The root must have `A/0` and be an actual mount point; no guessed reader and no
silently using a stale unmounted directory. Local mode also accepts `--card-root`
for a disposable copy. Both modes permit normal INI/history and guest writes.

Normal output contains short steps only; compiler details, commands, card-root
and PTY paths go to each shortcut's same-named `.log`. Logs are replaced per run
and separate CONFIGURE/BUILD or DESKTOP/MIRROR with blank lines and delimiters.
`--dry-run` is the explicit verbose exception: print the resolved command, do nothing.

== Shared services

* `target_mirror.py` supplies terminal selection to hardware and desktop:
  Konsole, then Kitty, then current terminal; `--mirror` overrides this.
* Desktop requires explicit PTY and isolated `7xtgv-desktop-*` session. It never
  discovers USB serial, enters hardware ACL handling or inherits an uploader.
* Preserved both `cpm-session.sh` changes: remote `stat -L` for symlink device
  permissions and local session-name isolation.
* `setup.sh --with-desktop` adds CMake, make, C++ and SDL2 development packages
  to the explicit detected Linux setup. Normal firmware setup stays unchanged;
  no packages were installed during this work. This option is additive, not a
  desktop-only installer, and cannot combine with `--serial-only`.
* The reported Linux desktop keyboard trouble is in the ChatGPT app, not the 7xtgv
  mirror. No terminal key mapping was changed in response.
