== Correction prepared

The initial helper incorrectly relied on digit virtual-key codes to identify
the main row and on the low word of HKL being the Czech language identifier.
Those are narrower assumptions than physical keyboard-position handling.

The mapper now derives row positions 1..0 from non-extended scan codes 02..0B.
The hook checks the actual unshifted layout row via MapVirtualKeyEx/ToUnicodeEx,
using a neutral modifier state and the existing non-mutating translation flag.
Only the complete configured row matches; detection is cached per active HKL.
Actual event fallback still uses the current modifiers and CapsLock state.

Thus plain/Shift Czech row events reach existing KeyNum0..9 defaults and INI
overrides independently of the Windows virtual-key names or input language.
Other layouts retain ordinary plain typing. AltGr/Win modifiers, active
composition and paste retain their existing bypass paths. Firmware and INI
syntax are unchanged. Native verification of this correction remains pending.

The existing `tools/terminal.conf` string `XTGV_BANK_KEYS='+ěščřžýáíé'` serves
Alt-bank selection in the shared mirror; it does not rewrite plain typing.
Petr requested a distinct, configurable plain-row mapping and approved
`XTGV_HACK_TOPROW='+ěščřžýáíé'` with an empty value disabling it.

The setting is now in that host configuration file. Windows launch and keyboard
probe tooling read just this literal assignment, with an inherited environment
value taking precedence. No shell commands or unrelated target/upload settings
are evaluated. The resolved Unicode value reaches Mintty's process environment,
where the hook reads it and compares the active layout's complete row. It is
also recorded in `key-bridge.log`. Missing/empty disables only plain/Shift row
conversion; decimal and brightness routes remain available. A different
ten-character row explicitly selects another layout. Current validation accepts
ten printable BMP characters, matching the UTF-16 keyboard-layout query.

The native helper has no hardcoded Czech row. Existing Konsole/Kitty generated
keymaps remain separate; the option currently controls the Windows helper.
Runtime snapshot packaging now includes `tools/terminal.conf` so local copies
retain this setting. Configuration changes require a new Mintty session.
