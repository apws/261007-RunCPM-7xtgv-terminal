=== Palette review addition (260923)

Petr requested that palettes also contain the active-line, cursor and gutter
colors. The values above are the compiled defaults from
`src/7xtgv-vt100-runcpm/src/terminal/history_profiles.h`, not values fetched
from the device. Their RGB565 equivalents are respectively `0xCFF9`,
`0x04A5` and `0x8410`. The current configuration stores RGB888 triplets and
the display runtime converts them to RGB565; final palette-file value syntax
remains to be agreed. The earlier `RGB565 ...` entries are placeholders.

The current active/panning gutter normally follows the active-line color.
An explicit `viewport_active_gutter_rgb` override also exists today. Moving
UI defaults into palettes must account for that policy and existing profile
overrides; no existing user INI is to be silently rewritten.

Petr clarified the intended ink encoding: indices 0..7 are the normal colors,
and 8..15 are their emphasis companions. Bit 3 (`0x08`) selects emphasis.
The current shared palette and terminal instead interleave normal/emphasis
pairs. Preserve the tuned RGB values while correcting the encoding; do not
treat the historical implementation's even/odd ordering as the desired spec.

Recommended implementation split, pending approval:

. Correct ink encoding in the shared palette, ANSI mapping, emphasis selection,
  direct terminal attributes, demo mappings/constants and tests. Preserve all
  visible colors. Merely moving the emphasis bit preserves the existing base
  hue order: grey, red, green, blue, silver, cyan, magenta, yellow. A different
  hue order is a separate choice; the raw labels above remain provisional.
. Externalize presets into the terminal INI, including the three UI colors,
  global palette selection, validation/fallback and shared TFT/mirror repaint.
  Define override precedence explicitly. Add runtime selection and persistence
  through the existing settings path once loading works.

Keep attribute-marker interpretation as a separate follow-up. Palette loading
does not require the four-plane native renderer or any xterm256 palette change.
