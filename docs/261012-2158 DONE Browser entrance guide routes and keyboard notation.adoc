== Intel MacBook Air observation

Petr reports limited browser use on an Intel MacBook Air on 261012:
some kbd:[Fn] combinations worked; kbd:[Alt+Space] did not; application exit
worked only with kbd:[Alt+Esc]. Browser/macOS versions and the exact Fn
combinations were not supplied. No cause is diagnosed from this observation.

UG is the maintained owner of this report, with RG and browser tooling links.
macOS remains unqualified beyond this limited observation. Apple documents
Fn navigation alternatives, but that does not establish delivery of the
project's multi-modifier chords. Control and Command remain distinct;
Option-generated text and reserved host shortcuts need actual keyboard tests.
See https://support.apple.com/en-us/102650[Apple's keyboard reference].

== Module identity and sources

Petr suggested that the old W535 material was stored under the wrong folder
name and that the module is probably JC3248W535. Guition's own
https://www.guition.com/-download[download index] now supplies primary
specifications for JC3248W535, JC8048W550 and JC8012P4A1C_I_W.

The W535 specification identifies a 320x480 ESP32-S3/AXS15231B module, consistent
with the project's rotated 480x320 ES3_35 target. The exact physical suffix is
still unconfirmed. Existing `jc8048w535` target/folder/boot strings are retained
and explained in BG; this is not a hardware rename or new variant acceptance.

The P4 manufacturer specification lists the I_W_Y and I_W_Y1 variants. BG also
links Petr's supplied
https://www.displaysmodule.com/sale-53106488-industrial-esp32-display-unit-jc8012p4a1c-i-w-y1-with-capacitive-touch-top-performance.html[supplier listing]
without asserting ownership of that domain. Manufacturer specification links
are the technical references. Grokipedia was a search lead, not the authority.

== Optional browser strips: still a proposal

Petr is not yet sure about the navigation/control strip. He also proposed using
FullHD monitor width for another strip with quick command help, particularly
`7XF` cataloged operation. Preserve both as possibilities, not accepted UI work.

A future layout could offer independently collapsible controls and quick
reference beside the display, with compact presentation on narrow windows.
Quick help could show `7XF`, `LS /`, `LS`, `LL`, `CD /B/MBASIC`, `VTINFO`
and the card-save reminder, linked to their existing guide sections. Help should
remain readable reference; making examples execute guest commands would be a
separate interaction decision. No new strip is documented as available.
