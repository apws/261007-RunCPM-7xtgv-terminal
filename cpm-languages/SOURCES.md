# CP/M language packages

- BBC BASIC: https://bbcbasic.co.uk/bbcbasic/z80basic.html and BBCZ80V5.zip from the author. This download is the v5.00 test package; original archive retained intact. The included README permits extracting BBCBASIC.COM for a genuine CP/M system. DIST.Z80 is the terminal patch source; cursor editing and timers need platform-specific work.
- Turbo Pascal: http://www.retroarchive.org/cpm/lang/TP_301A.ZIP (CP/M-80 3.01a archive). TPTERM.ZIP contains interpreter/editor, overlays/messages, TINST terminal installer/data/messages, and READ.ME. This is an archived commercial package, not claimed to be a newly free-licensed release.
- COMAL: http://www.retroarchive.org/cpm/cdrom/CPM/COMAL/DEM2CMAL.LBR. Extracted with https://github.com/avwohl/80un. CP/M COMAL 2.10 demo disables SAVE, ENTER and MERGE, according to STARTED.DOC. Initially configured for C128; INSTALL.COM + INSTALL.DAT configure a different terminal.
