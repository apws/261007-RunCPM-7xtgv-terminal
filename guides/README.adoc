= RunCPM 7xtgv-terminal: Guide Index
:leveloffset: +1
:source-highlighter: highlight.js

[#7xtgv-runcpm-terminal-manual]
Run the current RunCPM-based CP/M terminal on an MCU/TFT board or in its
*Linux or Windows* native SDL desktop emulator. Hardware and desktop use the PC mirror for input and the complete
logical screen. Start with the Build Guide for clone/setup, then the User Guide
for everyday controls.

Desktop setup, rebuild and launch follow the same workflow on both hosts.
Use `tools/targets/` with `.sh` launchers on Linux and `tools-win/targets/`
with `.cmd` launchers on Windows, relative to `src/RunCPM_7xtgv-terminal/`.
The matching commands are `desktop-rebuild`, `desktop-local` and `desktop-card`.
CP/M commands and terminal INI settings are shared; host mirror/transport and
some launcher options differ. Hardware build/upload is the Linux workflow.

This terminal implements a selected ANSI/VT100 and VT52 subset as a testbed
for the primary *7xtgv-native* engine objective; the native engine is not yet
implemented. The selected card's live `A0:7XTGVTRM.INI` and history may differ
from the committed repository copy.

The link:../docs/FEATURES.adoc[feature ledger] records individual implementation
and test status; the timeline is a hand-maintained compact historical view.
Implemented feature additions and behavior changes update both the ledger's
source `++docs/features.tsv++` and the timeline. Dated reports
under `docs/` preserve experiments and hardware evidence;
a historical report is not automatically the current device configuration.
For running geometry and firmware identity, use `++VTINFO++`.

BG, UG, RG and TRG group their topics into explicitly numbered main chapters;
TG numbers its existing main chapters. Lower-level topics remain unnumbered.
Use a short reference such as *RG 4* for a chapter, and a section link for an
exact topic. Section anchors are independent of the displayed chapter numbers.
The filename prefixes order the guides; they are not chapter numbers.

The guides use the ordered filenames `01-BG-` through `06-HG-` from 261010.
Links in the repository follow those filenames; external browser bookmarks to
the former filenames need updating. Existing topic fragments are retained.
HG remains a preparation outline for the author's account.

to root-level `guides/`, including their images. Old browser
bookmarks need updating; former section anchors below still link to their owners.
