Keyboard settings and help

Ten characters in positions 1…0; empty disables conversion. Session only.

Plain guest text accepts ASCII. Unsupported composed text is reported rather than silently converted. AltGr remains for text; some browser/OS shortcuts may be reserved. Paste is limited to 4096 characters.

Glyph zoom: Ctrl+Shift+PgUp / Ctrl+Shift+PgDn.

Brightness: Ctrl+Alt+Shift+PgUp / Ctrl+Alt+Shift+PgDn, Ctrl+Shift+1…9, and Ctrl+Alt+Shift+0 for OFF. F11 remains browser fullscreen.

Display scale uses whole CSS multiples with smoothing off. Fractional browser/desktop scaling is not compensated. Text snapshots contain the logical text grid; PNG captures include graphics at native resolution.
